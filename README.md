# IT Asset Management System

An enterprise-grade IT Asset Management web application designed to track, filter, assign, return, repair, and manage hardware assets across organizations with role-based access control (RBAC) and audit logging.

## Tech Stack
- **Frontend:** Angular, Tailwind CSS
- **Backend:** Go (Golang) REST API
- **Database:** PostgreSQL 16

## Features
- **Asset Inventory Tracking:** Monitor active hardware fleet, asset statuses (Available, Assigned, Maintenance, Retired), and locations.
- **Audit Ledger:** Complete event log capturing asset actions and modifications.
- **Role-Based Access Control (RBAC):** Admin, Operations, and Auditor access simulation.
- **CSV Data Export:** Quick export of inventory lists and audit trail logs.
